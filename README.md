# 🤲 NGO Management System — React Frontend



A modern, responsive user interface built with React and Vite for the NGO Donation Management System. This frontend connects directly to the Node.js/Express REST API backend to handle donor management, staff authentication, and donation tracking.



## 🚀 Tech Stack

* **Framework:** React.js (via Vite)

* **Routing:** React Router DOM (with Protected Routes)

* **HTTP Client:** Axios / Fetch API

* **Styling:** CSS / Tailwind CSS



## ✨ Features

* **Authentication Flow:** Secure login with JWT token handling and storage.

* **Protected Routes:** Prevents unauthorized user access to the NGO Dashboard.

* **Donation Dashboard:** Complete CRUD operations (View, Add, Edit, Delete donations) with real-time UI updates.

* **Form Validation:** Custom validation logic and clear user feedback on form submission errors.
